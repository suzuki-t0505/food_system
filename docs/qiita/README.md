# Qiita 投稿用ドラフト

実装で失敗したこと・解決したエラーを、Qiita に投稿できる形でまとめたドラフトの置き場所です。

- **作り方**: Claude Code で `/qiita-draft [題材]` を実行する（手順とテンプレートは `.claude/skills/qiita-draft/`）
- **命名**: `{YYYYMMDD}-{英小文字ケバブケースの題材}.md`（例: `20261109-credo-nesting-depth.md`）
- **1 記事 1 テーマ**。同じテーマは新規作成せず既存のドラフトを更新する
- **投稿は手動**。投稿前に、秘密情報・GCP のプロジェクト ID・個人情報・業務固有の情報が含まれていないかを確認する
- 投稿後もドラフトは履歴として残し、ファイル冒頭に投稿先の URL を追記する
